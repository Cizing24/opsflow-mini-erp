# RCA 記錄格式

正式案例使用以下欄位，內容必須來自實際證據。沒有發生或沒有驗證的項目標示未知。

- 類型：自然發現 Bug / Simulation，兩者不可混用。
- Issue、發現日期、受影響版本與環境。
- 現象、業務影響及最小重現輸入／交錯順序。
- RED 證據：實際輸出、HTTP 狀態、測試名稱或檔案。
- Root cause：錯誤所在的程式或資料假設。
- 修正與權衡：具體變更、資料處理、安全界線。
- Fix commit、GREEN 回歸證據及未驗證範圍。
- 後續追蹤：需額外監控或產品決策的項目。
