# OpsFlow ERP 產品說明

OpsFlow ERP 是虛構工程企業「海嶼系統整合有限公司」的營運展示系統。它把工程需求、主管簽核、採購、部分收貨及專案領料接到同一個 MySQL 資料庫，讓每筆成本可回查來源。用途是展示企業系統開發、交易一致性與維護能力。

## 實際使用情境

工程師提出包含多項物料的請購；主管確認規格與預算後核准，或退回補件、拒絕。採購人員由核准單建立唯一 PO，倉儲可分批收貨。工程師從指定倉庫領料時，庫存扣減與專案成本在同一交易完成。管理員在 Portal 查詢成本、異常與 Audit Log。

## 產品邊界

單一企業、TWD、固定標準成本，尚無會計總帳、稅額、應付帳款、付款、批號、庫存估價期間結轉、退貨、跨幣別或多租戶。供應商 API 是本專案獨立模擬服務，不會建立真實訂單。KPI 是模擬資料的計算結果，不代表企業導入後的改善成果。

## 角色

| 角色 | 工作 |
|---|---|
| 系統管理員 | 主檔、專案、跨部門管理與稽核；仍禁止自我簽核 |
| 部門主管 | 專案管理、同部門他人的請購簽核、成本報表 |
| 工程師 | 所屬專案的請購、退回補件、物料需求及領料 |
| 採購人員 | 供應商維護、建立 PO、CSV 匯出及模擬供應商查詢 |
| 倉儲人員 | 部分收貨、物料主檔、CSV 匯入／匯出、庫存查詢 |

介面選項依角色顯示；每一筆寫入仍由後端檢查角色與資料存取權限。
